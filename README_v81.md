# v81 独立下期双波色与100期回测

增加独立双波色模块，不用它删号，也不改变v80四组的评分、8热8冷、5热1最冷、两错换法或10期分轮。原四组内部版本保留v80，页面和备份应用版本为v81。不是复刻图片的未知算法。

## 算法

每期取两个波色，公式预先固定：近20期加权频率35%＋近60期加权频率35%＋本期波色条件转移30%。每个分布加入20期等效平滑先验，先验按49个号码中红17、蓝16、绿16的实际比例。转移最多看120期，只统计确实相邻、且已知的“前一期波色→后一期波色”对，不能把缺号两端当转移。

前两种波色开奖前锁定，同一期刷新不重选。新开奖后仅结算对应旧锁单，再生成下一期。正式统计从模块启用后开始，不补造历史预测。四组原有锁单、轮次和累计记录保留。
