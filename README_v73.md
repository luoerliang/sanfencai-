# V73 单算法精简版

按用户要求移除重复算法与旧界面，仅保留一个22码主输出、多策略池、最近20期正式锁单结算和平特一肖。

## 当前算法

统一使用既有Q1多尺度思路：近60期加权后验40% + 近360期加权后验40% + 历史转移后验20%，统一排序取22码。固定参数；不自动择优切换，不强行每期换码。六模型策略池独立保留趋势、生肖、冷热、波色、单双、纠错的观察与正式锁单。

此前R1/R2五组、Q2/Q3竞争席位、旧互补输出及v67规则实验不再产生新锁单。153个不可达旧函数已删除；共用训练、概率计算、生肖计算及历史结算工具继续保留。没有复制旧实盘成绩到新算法。

新版主输出使用新profile F_SINGLE_Q1_TOP22_v73。主算法命中统计从首次真实开奖前锁单开始。已有历史、旧锁单和旧统计不删除；归档未结算锁单仍可结算。没有正式锁单的期次显示“—”。

## 界面

主页面：最新开奖/下期/历史数、当前22码及复制、本轮20期和累计中错、六模型池、最近20期正式锁单表、平特一肖。

算法说明与历史开奖默认折叠。20期表固定最大225px高度，区域内滚动，不把整页拉长。号码23px；手机小屏21px。取消历代算法诊断、对照实验大卡片。

## 迁移与部署

更新原服务文件；保留原环境变量、备份配置和数据库位置，不新建空库。继续采用V72.1归档按期号补齐、全量开奖备份、迁移高水位检查。默认最低要求提高至已确认的15,744期、20261011454期；建议V72_REQUIRED_HISTORY_COUNT / V72_REQUIRED_LATEST_ISSUE设为更新前实际总数及最新期号。显式环境变量仍优先，其它已知来源高水位也纳入检查。
