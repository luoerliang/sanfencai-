# v67.2 不显示号码修复

修复两个会导致页面永久 `--码` 的状态问题：

1. 启动 quick cache 的期号已经是最新期，但号码数组为空。旧逻辑看到“期号一致”就直接返回空数组，不会自愈。
2. 新期开奖后如果缓存落后，旧逻辑会主动把 F/A/B/C/D 全清空，然后只等完整模型；这抵消了 v67.1 的“先出 BASE”设计。

v67.2：
- `/api/model` 发现号码为空时会同步生成五组 BASE。
- 缓存期号落后时先生成 BASE，再后台跑完整 Shadow。
- Shadow、统计、平特一肖、趋势任一组件报错，都不能再把五组号码拖成空白。
- 正常 v67 BASE scorer 报错时，才启用应急只读历史排序，并在页面明确显示“应急排名”；完整模型恢复后会覆盖它。
- F/A/B/C/D 与 v67 的正式码数不变：22/27/27/22/16。
