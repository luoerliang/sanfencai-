# v69 Null-First / 证据门控版

这版不是“更强预测器”，而是把 v68 深度审计的结论落实到程序。

## 核心变化

1. **Uniform 1/49 正式上桌**
   - 每期开奖前和模型一起锁定。
   - LogLoss 基准固定为 `log(49)=3.89182`。
   - Brier 基准固定为 `48/49≈0.97959`。

2. **R1 / R2 冻结，不再调参**
   - R1 沿用 v68 的 60/240 窗口和固定权重。
   - R2 沿用 v68 的 10/40 窗口和固定权重。
   - 修改任何窗口、半衰期或权重都必须换新的 model_version。

3. **取消 R3 独立模型身份**
   - R1/R3 在实盘和历史中高度相关。
   - D16 现在明确只是 `R1 Top16` 的研究切线，不再叫“独立R3”。

4. **Null-First 概率门控**
   - 默认 `lambda=0`。
   - 官方概率仍是 Uniform。
   - R1/R2 的号码列表只是冻结挑战者的研究切线。
   - 只有前瞻证据通过，才有资格讨论让 lambda > 0。

5. **页面评价改成 ΔLogLoss**
   - `ΔLogLoss = 模型LogLoss - UniformLogLoss`
   - **负数才是好事**。
   - 同时看 Top-N Lift、Brier、真实特码平均排名。

6. **Shadow 全局 Holm 校正**
   - 不再用“净+2 / 净+8”就叫候选。
   - 所有旧规则的 rescue/harm 先做配对检验，再统一做 Holm 多重比较校正。
   - 页面只显示：研究中 / 证据通过 / 证据失败。

## 数据纪律

- v68 的旧473期证据继续保留在数据库/归档面板。
- v69 自己从部署后的下一次真实前瞻开始记账。
- 不用已经开奖的结果补造 v69 预测。
- Supabase/SQLite checkpoint 逻辑保持原样。

## 注意

彩票开奖具有随机性。当前证据没有证明 R1/R2 比 Uniform 更有预测优势。v69 的目标是严格验证，而不是承诺盈利。
