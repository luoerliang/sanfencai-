# v72 我自己的独立算法 · 可部署版

基于 v71 继续升级，**不是**旧的 v7 包。保留所有现有接口、Telegram 收录、部署文件、原历史 CSV、v68/v69/v70/v71 统计；新增 v72 独立实验区，并不声称已经改善未来命中率。

## 选码方式

- O1 长期稳健算法：随机 Uniform 先验 75%，历史24/100/400/1000期的指数衰减频率后验 25%；F22、A27、D16 由它排序切线，不硬杀波色、头、生肖。
- O2 短期稳健算法：随机 Uniform 先验 80%，24/100/400期衰减后验20%；C22、B27 由它排序切线。
- 这些固定权重是待检验的工程假设，不是用本期号码回推出来的；历史表现不能保证前瞻优势。
- 只有在开奖前插入 `v68_forecast` 独立新版本的锁单记录；开奖后进行结算，不回填过去期数。UI 每组显示当前锁定号码及独立累计命中率。
- 500期以下全部标为样本不足；500期以上通过随机基线还须与旧模型配对验证，**不自动替换 Live，也不提供自动下注接口**。

## 重要：数据迁移

ZIP 的 `history.csv` 包含原版 14,343 行历史基础数据，但是 ZIP **不含生产服务已追加的最新 Telegram 开奖记录或外部数据库**。必须先备份生产历史、原数据库/外部存储并确认总数、最新期号，再切换部署。禁止将 ZIP 内旧 CSV 覆盖现有更新的生产历史。首次部署后 v72 Shadow 从 0 期开始，不可回填旧期冒充前瞻。

赔率按每码1单位、命中时总返回47.5单位算，16码、22码、27码回本命中门槛分别约33.68%、46.32%、56.84%。软件不证明彩票存在可预测信号，请勿将未验证预测当作获利依据。
