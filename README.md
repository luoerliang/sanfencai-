# 三分六合彩 v51：B组动态杀一头

## A组
A组完全不变：
- 27码一组打10期
- v49/v50的冷肖可行性、波色单双、0/4规则全部保留

## B组
B组仍然每期开奖后重算下一期27码。

实时输入：
- 刚刚开奖的最新一期
- 再往前10期
- 合计11期实时窗口
- T/Z/C/W/A长期学习结果
- 历史转移关系

新增：

`0头 / 1头 / 2头 / 3头 / 4头` 五头同时评分，
每一期动态找出相对最弱的一头，B组27码彻底排除这一头。

## 为什么要做“基准校正”
0头只有01~09，共9个号码。
1/2/3/4头各有10个号码。

所以不能只按“最近开了几次”比较，否则0头天然容易显得更少。

v51先按理论概率校正：
- 0头基准 9/49
- 1头 10/49
- 2头 10/49
- 3头 10/49
- 4头 10/49

再综合：
- 模型综合强度 40%
- 最近11期头数走势 30%
- 最近30期头数走势 20%
- 最新转移模型 10%

分最低的一头作为当期B组杀码。

## 信号强弱
最弱头与第二弱头的差距：
- 差距 >= 0.10：强信号
- 0.05~0.10：中信号
- < 0.05：弱信号

即使是弱信号，按你的要求B组仍然会动态杀一头，但页面会明确写“弱信号”。

## 实盘验证
B组使用新的独立profile：
`27B动态杀头v51`

从部署后的下一期重新统计：
- 已开
- 中
- 错
- 最近20期命中率
- 动态杀头成功率

同时显示理论基准。
因为“随便杀一个头”本来就大约有80%的概率避开，所以不能只看杀头成功率；
真正要看的是：

`实际杀头避开率 - 理论基准`

只有长期高于基准，才说明动态杀头本身有信息价值。
