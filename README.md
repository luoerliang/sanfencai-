# 三分六合彩 v41：27码前20期结构长码 + 数据链修复

## 27码：按你的长码规则
一轮仍然打10期。

### 1. 每轮开始先看前20期特码
统计6类：
- 红单
- 红双
- 蓝单
- 蓝双
- 绿单
- 绿双

如果最少的两类在20期里合计只出现 **4次或以下**，这两类作为弱势结构排除。
如果不满足“两类合计<=4”，但最低一类只出现0~1次，只排除这一类。

### 2. 0头 / 4头
同样看前20期特码：
- 0头比4头少 -> 杀0头
- 4头比0头少 -> 杀4头
- 一样多 -> 不杀头

### 3. 正常情况长码不动
本轮27码生成后继续使用，不因为一期开奖结果马上追着换。

### 4. 连续2期逆势 = 变盘检查
如果原来已经杀掉的：
- 波色×单双结构，或
- 0头 / 4头

连续出现2期（第3期仍连续也算），程序认为旧走势可能变化。

这时重新看“最新前20期”：
- 哪个波色×单双现在变少
- 0头 / 4头现在谁更少

如果新的弱结构和旧的不同，就进入下一“长码段”，重新生成27码。
同一轮10期继续累计，不重新开一轮。

## 仍保留统计
- 核心23中几
- 机动4救回几次
- 第28码救回几次
- 整轮最终10中几
- 变盘几次

## 第28码
仍然只有非常强的27码外覆盖信号才临时加入，并且不会把当前正在排除的弱结构又救回来。

# 两个程序故障已修复

## 故障1：v40的27码统计会报错
原因：SQLite Row 不支持 `.get()`。
v41已经转换成普通dict后再读取。

## 故障2：480期跨日
旧代码用“期号+1”，所以：
`20260924480 + 1` 会错误变成 `20260924481`。

v41统一改成：
- 20260924479 -> 20260924480
- 20260924480 -> 20260925001
- 20260925480 -> 20260926001

10期区间结束期号也同步支持跨日。

## 缓存自愈
如果历史开奖已经更新，但预测缓存还停在旧期：
- 页面不再显示旧F/27号码冒充新预测
- 自动显示“正在重算真正的下一期”
- 后台自动重建缓存

## 数据原则
停掉期间没有开奖前真实锁单的期，不倒补命中成绩。
历史开奖结果仍继续用于训练。

v40已有历史、F、T/Z/C/W/A、AI、纠错AI、Supabase检查点全部继续继承。
