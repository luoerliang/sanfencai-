# 三分六合彩 v31：趋势主攻 + AI专门纠错

这版不是继续堆更多指标，而是重新分工。

## 1. 生肖模型独立升级
20码/27码判断热肖、中肖、冷三肖时现在同时看：

- 特码生肖近期热度
- AI生肖概率
- 当前7个号码的生肖结构
- 历史“当前状态 -> 下一期特码生肖”转移
- 上一期/上两期生肖上下文
- 生肖遗漏与冷肖反弹
- 生肖轮动 / 热肖延续状态

冷肖如果很久没开、但生肖转移信号明显抬升，不会仅凭“冷”就机械排到最冷3肖。

## 2. 趋势做主模型，AI不再复制趋势
旧互补的问题是AI和趋势太像，容易一起中、一起错。

v31改成三层：

- 趋势主模型：约 65%~80%
- 基础AI：约 9%~11%
- 纠错AI：约 6%~23%

纠错AI只在趋势失败时训练，例如：

- 实际特码被趋势排在20/27码之外
- 实际特码所在生肖被列入冷三肖
- 0/4头杀错
- 实际特码落在21~27名边缘区

因此AI的任务变成“学趋势的错题”。

## 3. 20码 / 27码分开学习
新增两个独立纠错大脑：

- 20码纠错AI：反应更快，最高约23%
- 27码纠错AI：更稳定，最高约17%

两套权重分别保存，不再共用一套修正参数。

## 4. 排名落点统计
每期开奖前保存完整01~49排名。

开奖后自动统计实际特码原来在：

- 1~10名
- 11~20名
- 21~27名
- 28名以后

这样20码没中时能区分：

- 排名其实不错，只是被截断/生肖配额挤出
- 冷三肖误杀
- 杀头误杀
- 底层排序本身就错

## 5. 0/4杀头独立验证
每次杀0头/4头都会在开奖前锁定。

开奖后单独统计：

- 杀头次数
- 成功次数
- 成功率
- 是否因为杀头直接把实际特码踢掉

27码仍按你的规则：每10期固定一组，并且每组必杀0/4其中一头。

## 6. 状态切换
自动识别当前更像：

- 冷码反弹
- 头数集中
- 波色单双偏态
- 生肖轮动
- 热肖延续
- 高随机
- 平衡

不同状态会调整生肖/结构/纠错权重，不再所有时期固定一套参数。

## 7. 红单/红双/蓝单/蓝双/绿单/绿双
沿用v30：
- 趋势模型独立跟踪
- 基础AI也学习
- 纠错AI训练时同样能使用这些特征

## 8. 数据继承与Supabase
继续完整保留：

- 旧 prediction_log
- AI在线历史
- 旧互补在线历史
- 20码/27码真实记录
- AI基础权重
- 新的纠错AI权重
- 新的排名/误杀审计
- Supabase自动备份与恢复

旧验证不会因为v31故意清零。

## 重要说明
这版的目标是让“趋势”和“AI”真正分工，并定位错误来源。
彩票结果若接近随机，任何模型都不能保证提高命中率；是否改善应看部署以后开奖前锁定的真实样本。
