# 三分六合彩 v53

## 这版不改选号算法，只改三组成绩统计显示

### F动态
继续：
- 每期重新算号码
- 每20期开奖为一轮

显示两套成绩：

`本轮20期 · 已开 8/20 · 中5 · 错3`

以及一个独立小区域：

`累计实盘：中 27期 · 错 18期`

本轮满20期会归零；
“累计实盘”不会归零。

---

### A组27码
继续原来的：
- 一组打10期
- 变码时重新开10期

原来的本轮：
`已开 X/10 · 中X · 错X`

下面新增：

`累计实盘：中X期 · 错X期`

A组换轮不会清掉累计实盘。

---

### B组27码
B组选号规则完全不改：

- 只看最新20期官方开奖记录
- 每期开奖入库后重新生成下一期27码
- 不受A组、F、六模型池影响
- 动态杀0/1/2/3/4其中一头
- 最冷3肖每肖固定2码
- 其他热肖/中冷肖每肖最多3码

新增“20期一轮”的成绩显示：

`本轮 20260925xxx—20260925xxx · 已开 7/20 · 中4 · 错3`

第20期结算完以后，
下一期自动进入新一轮：

`已开 0/20 · 中0 · 错0`

同时B组也有：

`累计实盘：中X期 · 错X期`

所以B组现在有两个概念：
1. **分析窗口**：永远是最新20期开奖结果，逐期开奖滚动
2. **成绩轮次**：每20个提前锁单结果为一轮，满20重置

这两个互不冲突。

---

## “累计实盘”的口径

三个区域统计的都是各自当前策略 profile 的真实开奖前锁单记录：

- F：当前F策略从开始记录到现在
- A：当前A组长码策略从开始记录到现在
- B：v52纯近20期B组从开始记录到现在

只统计已经结算的真实前瞻记录，不倒推、不补历史中奖。

轮次归零只重置“本轮”，不会清除“累计实盘”。
