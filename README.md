# 三分六合彩 v52

## 1. 多策略模型池全部改中文

页面不再显示 T / Z / C / W / A。

现在直接显示：

- 趋势
- 生肖
- 冷热
- 波色
- 单双
- 纠错

并且“波色”和“单双”已经真正拆成两个独立模型，不只是改名字。

波色模型只研究红 / 蓝 / 绿。
单双模型只研究单 / 双。

因此现在模型池是6个独立模型。

旧的趋势、生肖、冷热、纠错实盘记录继续继承；
新的“波色”和“单双”从v52开始分别独立锁单验证。

## 2. B组动态27码彻底独立

B组不再使用：

- A组27码逻辑
- F动态码
- 六模型池权重
- 长期历史模型
- 其他纠错层

B组只读取：

`最新20期官方开奖记录`

每期开奖进入数据库后：
1. 最新20期窗口向前滚动1期
2. 重新分析20期
3. 重新生成下一期B组27码
4. 开奖前锁单
5. 开奖后记录中 / 错
6. 下一期开奖再滚动重算

所以B组现在就是单独的“近20期实时实验组”。

## 3. B组动态杀头

只用最近20期判断：

- 0头
- 1头
- 2头
- 3头
- 4头

哪一头相对最弱，就排除哪一头。

0头只有9个号码，其他头各10个号码，
所以程序仍然先做理论基准校正，避免0头天然吃亏。

## 4. B组生肖数量

B组只根据最近20期特码生肖找最冷3肖。

最冷3肖：
`每肖固定2码`

例如冷三肖是：
`鼠、狗、猪`

那么必须：
`鼠2码 + 狗2码 + 猪2码`

其余热肖、中冷肖：
`每肖最多3码`

不会再出现某个生肖塞4个、5个码。

## 5. 实盘记录

B组从v52使用独立profile：

`27B纯20期v52`

只统计部署后的真实提前锁单结果。

页面继续显示：
- 已开几期
- 中几期
- 错几期
- 最近20期命中
- 当前杀哪一头
- 当前三冷肖和每肖2个码

## 6. A组和F

A组原来的10期长码规则不动。
F动态原来的实时学习与救援规则继续保留。

只是B组现在与它们完全隔离，A组/F怎么变化都不会改变B组27码。
