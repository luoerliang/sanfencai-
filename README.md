# 三分六合彩 v64

## 新增 D组16码

D组是独立“波色组”，每期开奖后重算16码。

### D算法
只组合两类波色信号：

1. **多策略池波色模型：60%**
   - 使用现有六模型池中的正式“波色”模型 W
   - 读取模型当前对红/蓝/绿的强弱判断

2. **最新10期波色：40%**
   - 只看最新10期的特码
   - 统计红/蓝/绿
   - 越新的开奖号权重越高

两部分融合后得到下一期：
`红 / 蓝 / 绿` 三个波色强度。

### 16码怎么分
为了不把16码全部压到一种颜色：

- 每个波色先保底4码，共12码
- 剩余4个席位，按融合后的波色强弱动态分配

例如可能出现：
- 红6 / 蓝5 / 绿5
- 红7 / 蓝5 / 绿4
- 红5 / 蓝6 / 绿5

然后在每个波色内部，用六模型综合分 + 正式波色模型分挑最强号码。

D组不使用：
- B/C杀头
- 冷肖
- 缺尾补码
- A组10期长码规则

所以它是一个独立的纯波色实验组。

## D统计
D和B/C一样：
- 每20期开奖为一轮
- 显示已开 / 中 / 错
- 显示累计实盘中 / 错
- 使用独立profile：`16D多策略波色+近10期v64`
