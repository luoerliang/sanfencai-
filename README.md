# 三分六合彩 v63：B/C近10期缺尾补码

## 你的新尾数规则

每期开奖后只看最新10期特码。

先统计：
`0尾、1尾、2尾、3尾、4尾、5尾、6尾、7尾、8尾、9尾`

哪些尾数在这10期里一次都没有出现，
就把它们定义为：

`缺尾`

例如最近10期没有出现：
`2尾、7尾`

那么下一期B/C都会保证：
- 至少有1个2尾号码
- 至少有1个7尾号码

## “根据杀头尾数加上”怎么执行

假设当前杀：
`2头`

而缺尾是：
`7尾`

7尾号码有：
`07、17、27、37、47`

因为2头被杀，所以补7尾时优先从：
`07、17、37、47`

里面按当前综合分选最强的一个，
不会拿27来做缺尾补码。

## B组
B仍然固定27码。

缺尾补码不是把27码变成28、29码，
而是：

`加入缺尾强码 -> 踢掉一个当前最弱码`

同时尽量继续保持：
- 冷3肖每肖2码
- 其他肖最多3码
- 杀头规则
- 尾数10%软评分

所以B只是重新分配27个位置，不增加总码数。

## C组
C仍然固定22码。

每个缺尾也至少保1码。
补码同样优先避开当前杀头，
然后替换C里较弱的号码。

C原来的：
- 杀头软降权
- 冷3肖总保4~6
- 生肖软约束
- 独立22位优化

继续保留。

## 页面显示

B/C下面会直接显示类似：

`缺尾 2尾/7尾 · 补 2尾:32 · 7尾:47`

这样你一眼就能看出：
- 最近10期哪些尾没出
- 程序给每个缺尾补了哪个号码
