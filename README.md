## B组：每期动态27码

B组每期开奖后都重新计算下一期。

实时窗口固定为：

`刚刚开奖的1期 + 再往前10期 = 11期`

因此每次官方开奖记录进入数据库后，B组都会使用最新11期状态重新计算。

B组同时不是只看11期：
- T/Z/C/W/A长期学习结果作为底座
- 最近11期号码变化
- 最近11期波色×单双
- 最近11期头数
- 最近11期生肖
- 最新一期到下一期的历史转移

最后融合成新的27码。

## 数据更新/学习

现有自动流程继续保留：
1. 新期开奖进入历史数据库
2. 结算上一期提前锁定结果
3. 更新AI/模型表现与纠错数据
4. 重算F、A组、B组下一期号码
5. 在下一期开奖前锁单
6. 写检查点并远程备份

因此B组是真正的“实时更新、实盘记录、实时优化”，但命中率是否更高仍由之后的真实前瞻样本验证。
