# v79 四组 · 十期分轮 · 连错两期换方法

保留算法22、算法16（近20期）、多策略22，新增6肖24码。每期重算并在开奖前锁定，升序显示，两位数英文逗号复制。

## 十期统计

原三组从已继承的首个正式锁单起连续划分10个期号为一轮，升级不会丢失累计成绩。新增24码从首次锁单起计轮。每组显示本轮起止期号、已开/10、中、错及过去轮次。号码仍每期计算，并非固定10期。

每个目标期只结算一次。缺开奖或缺锁单不会冒充“错”；历史轮可能只开8/10，继续保留并等待补数据。跨日480到次日001正确延续。累计统计含旧版，历史回测不计入正式成绩。

## 连续两期不中自动切换

每组独立记录当前方法的正式表现。同一方法在相邻两个期号连续不中，下一未锁期必须换成另一方法；不会再依赖融合证据门槛阻止你要求的这次切换。先对替代方法用开奖前历史逐期比较，再选替代方法；页面显示当前方法、连错数和“连续2期未中”切换原因。

切换后从新方法重新观察连错，但本轮和累计统计不清零。缺开奖的期号不算错，也不把隔了缺号的两次错误判为相邻两期。相同目标期刷新仍沿用原锁单；升级时原三组已有锁单不会被临时改写，新增24码可以单独加入当前目标期，从下个新目标期原三组开始使用新逻辑。

方法池：算法22（中长窗/融合/冷热平衡）、算法16（20期短窗/20期冷热平衡/20期结构）、多策略22（均衡投票/表现加权/波色单双结构）、6肖24（生肖综合/生肖转移/生肖冷热平衡）。16码的原始号码评分与替代方法比较均只用最近20个期号的已知开奖；正式连错记录用于选择方法，不暗中扩大号码训练窗口。

未触发两错的情况下，新的加权融合只有在前40次逐期比较同时优于原方案和同码数理论基线、且检验达到设定门槛时启用。两错强制切换和这个普通融合门槛是两条不同规则。

## 6肖24码

从12生肖中选6个，每肖4码，严格24个不同号码。根据最新实际开奖标签校准年度生肖映射；2026马有5个号码，被选中时按号码评分择4个。默认采用平滑生肖频率、生肖转移和号码模型支持。六肖命中与24码命中分开结算，不能用生肖中冒充号码中。
