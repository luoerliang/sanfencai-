# 三分六合彩 v66：减法验收版

这版不再继续加预测规则，核心目标是判断“加工到底有没有用”。

## A/B/C/D新增同码数原始基准
每期开奖前同时锁：
- A加工27码 vs A纯六模型Top27
- B加工27码 vs B纯六模型Top27
- C加工22码 vs C纯六模型Top22
- D加工16码 vs D纯六模型Top16

全部都是开奖前锁定，开奖后只结算，绝不回填。

页面新增“v66规则验收”：
- 加工中多少
- 原始中多少
- 加工独中 / 原始独中
- 净值
- 当前判断

## 判断门槛
不因为10期、20期就乱改。

至少：
- 40个配对前瞻样本
- 至少12个“加工和原始结果不同”的差异样本

再用配对检验判断。

如果原始Top-N显著胜过加工：
`加工规则负增益`

如果加工显著胜过原始：
`加工规则有增益`

否则：
`无显著差异 / 继续观察`

## F减法
继续保留：
- 4/6、5/6、6/6绝对保留
- 强3/6优先

收缩：
- 1/6独家救援：完全停用
- 2/6：前40期不启用
- 40期后只有F同码数实盘“救回>=误伤”才允许
- 每期除4+/6绝保外最多1次普通调整

## 随机覆盖基准
页面和统计里同码数理论基准仍可对照：
- 27码：55.1%
- 22码：44.9%
- 20码：40.8%
- 16码：32.7%

这些只是随机覆盖参考，不代表程序应当保证达到或超过。

## 其他
A/B/C/D原算法仍保留，让它们和原始Top-N真实对打。
v66先收集干净证据，再决定下一步删哪条规则。
