## C组22码
新增C组22码，和B组放在同一套实时逻辑下。

C组不是另写一套算法，而是直接调用B组算法：

- 只看最新20期官方开奖记录
- 每期开奖后实时滚动20期
- 每期重新生成下一期号码
- 动态分析0/1/2/3/4并杀其中一头
- 最冷3肖每肖固定2码
- 其他热肖/中冷肖每肖最多3码
- 不受A组、F、六模型池长期权重影响

区别只有：
- B组 = 27码
- C组 = 22码

因此可以直接比较“同算法27码”和“同算法22码”的真实前瞻表现。

C组也有：
- 每20期一轮
- 已开 / 中 / 错
- 满20期下一期归零重开
- 累计实盘中 / 错

## 平特一肖
平特一肖也不再用旧的长期AI/转移算法。

现在只使用B组思想：
- 最新20期
- 每期开奖后滚动
- 不使用A组/F/长期模型池
- 看20期内7个开奖号的生肖出现强度
- 最新6期加速
- 加少量遗漏修正
- 选下一期最强一肖

页面显示：
- 当前平特一肖
- “B组算法 · 近20期实时滚动”
- 该新算法从v54开始的真实实盘中 / 错
