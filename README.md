# 三分六合彩 v56：平特一肖多节奏动态

## 为什么改
v55虽然每期开奖后都会重新计算平特一肖，
但20期总体权重太重，所以第一名容易长期不换。

v56改成真正的“快/中/慢”多节奏结构。

## 只用最新20期
平特一肖仍然不受：
- A组
- F动态
- 六模型池长期权重
- 长周期AI

影响。

只使用最新20期官方开奖记录。

## 每期开奖后重算的6个部分
1. 近3期突变：24%
2. 近6期走势：22%
3. 近10期中短节奏：17%
4. 近20期底座：13%
5. 连续出现修正：10%
6. 连续遗漏修正：6%
7. 上一期生肖组合→下一期生肖转移：8%

（总和100%）

其中“转移”也只从最新20期内部学习，不调用长期历史。

## 不再有“这期有鼠，下期默认还有鼠”
程序每期开奖后会把12肖全部重新评分。

如果鼠仍然第一，就继续鼠；
如果马、蛇、兔等任何生肖的新综合分超过鼠，就会立即换。

也就是说：
`上一期出现鼠 ≠ 下一期必有鼠`

## 页面新增解释
页面会显示类似：

`当前 鼠 78.4分 · 第二 马 74.9分 · 弱优势`

这样可以直接看：
- 为什么还没换
- 第二名是谁
- 当前领先到底强不强

## 实盘统计
因为算法已经实质改变，v56使用新独立profile：

`平特一肖多节奏v56`

从部署后的下一期开始重新积累真实前瞻中/错，
不把旧算法成绩混进来。

其他F/A/B/C功能全部不变。
