# 三分六合彩 v35：稳定紧凑界面 + F20错题自修融合

## 界面调整
- “下一期预测状态”稍微放大，但每个状态格固定高度
- 刷新时文字不会因为换行长短造成页面上下弹跳
- 20码、27/28码改成10列小号码球，明显减少高度
- 多策略模型池压成5个小格
- 4肖4码和平特一肖合并到同一个功能区
- 保留一键复制英文逗号格式

## T / Z / C / W / A 错期分析
每套模型继续开奖前锁单。

系统自动统计：
- 最近10期错几期
- 最近30期错几期
- 最近60期错几期
- 当前连续错多少期

短期连续错误只会“小幅降权”，不会因为两三期输赢就把模型权重清空。

## 旧AI和趋势也分析
同时统计：
- AI在线最近60期错几期
- 当前对比趋势模型最近60期错几期

这两套旧口径不直接和20码模型等同，但会参与“盲点类别”分析。

## 自动改进：盲点修正
系统分析T/Z/C/W/A、旧AI、趋势真实错期里的：

- 生肖
- 头数
- 红单/红双/蓝单/蓝双/绿单/绿双
- 重复漏掉的具体号码

形成“错题盲点修正分”。

为了防止追错：
- 样本少时不启用
- 启用后只占F=20码约5%~12%
- 错期越多、样本越成熟，修正比例才慢慢增加
- 仅融合到最终F=20码，不强行改27码

所以F=20现在是：
基础趋势/AI + 多策略模型池 + 小比例错题盲点修正。

## 27码
继续沿用v34：
- 10期一轮统计
- 轮内每期重算
- 不强制杀0/4
- 多策略确认弱头才排除
- 强外码可以弹窗并补成第28码

## 数据继承
没有新建需要手工迁移的数据文件。
所有错期分析直接读取原 prediction_log，因此：
- 历史记录继续继承
- Supabase备份继续有效
- 原AI、纠错AI、20/27码成绩都保留

> 彩票结果具有随机性。“自动改进”指根据已锁定的历史错误做有限权重/盲点调整，不保证未来命中率一定提高。
