# 三分六合彩 AI×趋势互补版 v29

## 目标
不再只是 `AI 38% + 趋势 62%` 的加权平均。

现在24码使用：
**共识优先 + 分歧互补 + 独立实盘验证**

## 24码仍严格保持
- 12肖 × 2码
- 每个生肖固定2码
- 共24码
- 每期开奖后重新计算

## 每个生肖的两个位置
1. **共识码**：AI与趋势都认可的稳定位置。
2. **互补码**：故意保留AI侧或趋势侧的独立意见。

不会因为某一边短期高一点，就把另一边全部压掉。

## AI/趋势补位名额怎么分
程序读取真实 `prediction_log`，比较同一期：

- 双方都中
- AI独中
- 趋势独中
- 双方都错

然后决定12个“第二码席位”怎么分给AI与趋势。

保护范围：
- AI最少4席
- AI最多8席
- 趋势因此也最少4席、最多8席

避免任何一个模型垄断24码。

## 旧验证不会被清零
原来的：
- AI在线
- 趋势快/平衡等
- prediction_log
- 41+期真实验证
- AI权重

全部继续保留。

新增的是：
`互补在线`

它从v29部署后的下一期开始独立记录真实命中，
不会把历史开奖结果倒推成“假实盘”。

## 页面新增
“AI × 趋势互补”卡片显示：

- 双方都中
- AI独中
- 趋势独中
- 双方都错
- 当前AI/趋势第二码席位
- 互补在线几中几

## 数据安全
沿用v28F1：
- Render Free
- Supabase Free Storage
- 自动上传 `sanfen_ai_checkpoint.json.gz`
- 重部署后自动恢复
- Secret key 新版 `sb_secret_...` 支持
- prediction_log / AI权重 / learner_scores / 最近开奖记录一并备份

## 注意
互补机制的目的是利用两套模型“犯错位置不同”的信息，
不是保证命中率一定提高。新互补模型应以开奖前锁定后的真实样本评估。
