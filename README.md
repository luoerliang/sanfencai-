# 三分六合彩 v30：20码 + 27码双策略 / AI趋势增强

## 20码
- 一期开奖后立即重新计算下一期
- 每期一换
- 彻底不取最冷3肖
- 剩余9肖默认各2码
- 前3热肖最多3码
- 两个最佳热肖各补1码，合计20码
- AI+趋势判断0头/4头
- 当其中一头明显偏弱时，20码彻底杀掉该头
- 被杀后的空位只从热肖 / 中位肖补，不从最冷3肖补

## 27码
- 10期固定一组
- 同一个十期区间内不会每期开奖乱换
- AI + 趋势联合判断
- 每一组都必杀0头/4头其中一头
- 从热肖 + 中位肖选27码
- 最冷3肖不进入27码主体
- 页面显示本轮杀0头还是杀4头
- 单独保存 `27码十期` 的开奖前预测
- 单独统计本轮几中几，以及最近完整10期“10中几”

## AI与趋势同时增加六类走势
不再只是AI学习。

AI和趋势两边都加入：
- 红单
- 红双
- 蓝单
- 蓝双
- 绿单
- 绿双

趋势模型会把这6类作为独立走势参与号码评分。
AI增加4个不同周期的六类组合特征，并在100期滚动训练里加入这个训练目标。

## AI/趋势互补调整
旧版互补可能为了保留“分歧码”而过度奖励双方意见不同。

v30主20码改成：
- AI/趋势共识优先
- 一致性加分
- 号码结构加分
- 热肖加分
- 红蓝绿×单双走势加分

旧的 `AI在线`、`互补在线` 和历史记录不删除，仍然可以作为对照。
新的20码和27码从部署后的下一期开始单独做真实前瞻验证。

## 数据不会因为本次升级故意清零
沿用：
- Supabase免费外部备份
- prediction_log
- AI权重
- learner_scores
- 历史开奖记录
- 原有真实验证记录

新增的两个独立验证 profile：
- `20码精选`
- `27码十期`

注意：减少候选数、杀头、排除冷肖都会同时降低覆盖面。程序会按规则执行，但不能保证真实命中率一定提高，应以后续开奖前锁定的真实样本判断。
