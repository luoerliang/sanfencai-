# v80：24码5热1冷，16码冷侧分散

24码每期只选5个热肖和1个最冷肖，每肖4码。最冷肖按近60期已收录特码频次除以生肖号码数比较，同分看遗漏，再稳定解同分。五个热肖从其余生肖按近期热度选取；三个方法使用20/60/90期热度窗口，切换后仍只防一个最冷肖。页面分别列出热肖和防冷肖。

16码仍固定8热8冷、只使用最近20个期号的已收录开奖。冷8改为未开或仅开1次、且不在热8中的低频号码；每个波色+单双组合最多2码，并给重复生肖与尾数减分，避免冷侧集中。热冷不重叠，合并仍为16个不同号码。

连续2期不中换方法、每组10期分轮、本轮中错和累计记录全部保留。当前已锁期不改写，新规则从下一未锁期启用。缺开奖不算错，窗口不假补满。六码肖是否选中与24码是否命中分开结算。
