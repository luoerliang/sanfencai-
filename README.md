# 三分六合彩 v31：A组24码、B组27码

## A组：24码，每期开奖后更新

按历史遗漏与冷热指标找出三个冷肖。两个最冷肖不取码，第三个冷肖保留1码；其余生肖先各取2码，再向评分较高的中间偏热生肖各补1码，共补5码。合计24码。号码仍结合AI、趋势及其前瞻互补记录挑选。

## B组：27码，每10期更新一次

三个冷肖各保留2码，选码兼顾冷码；其余生肖先各取2码，再由评分较高的生肖各补1码，共27码。10期以当日开奖期号001–010、011–020等划分。首次生成后保存到数据库和远端检查点，同一区间即使重启也不会改变。

A组和B组有各自的开奖前锁定记录，分别从新版开始积累真实验证；旧的`prediction_log`、AI权重和历史记录继续沿用。代码在部署时优先恢复现有数据库与Supabase检查点并补抓开奖记录，只有本地历史不足时才使用包内的初始CSV。部署后请核对最新期号、历史总数及已锁定记录，再使用新版结果；压缩包内历史CSV不是线上最新数据。

## 平特一肖

原方法主要依赖一段时期的频率和转移分数，领先的生肖可能连续多期保持第一。本版查看开奖前锁定的`互补在线`记录：如果当期评分第一的生肖连续两期预测落空，则改取当期第二名。页面显示改选原因。已锁定的当期预测不会在开奖前改写。此规则仅调整模型选择，不保证命中。

## 界面

A、B两组号码使用更小的紧凑排列，均可单独复制。B组显示当前保留区间的终止期号。历史区域只在内容变化时重绘，以减小界面跳动。
