# 三分六合彩 v33：多策略并行锁单 + 连中统计

## 为什么加这一层
之前 AI 和趋势过于同质化，容易一起中、一起错。

v33 不再只比较“AI vs 趋势”，而是同时运行五套性格不同的模型：

- T：趋势结构
- Z：生肖转移 / 7码生肖结构
- C：冷热 / 反弹
- W：红单红双蓝单蓝双绿单绿双
- A：AI纠错

每套都在开奖前锁定自己的20码，开奖后单独结算。

## 动态权重
每个模型真实锁单成绩按：

- 最近10期：30%
- 最近30期：35%
- 最近60期：35%

进行平滑评分。

权重不会因为几期运气突然全压一个模型：
- 单模型最低约10%
- 单模型最高约35%
- 前30期逐渐增加模型池影响
- 样本越成熟，真实战绩影响越大

模型池最终参与20码和27码的01~49排序。

## 独中统计
除了命中率，还记录每套模型最近60期“只有它命中、其他模型都没中”的次数。

如果一个模型长期没有独中贡献，就说明它只是在复制其他模型。

## 最近10期正式锁单表
网页新增：

期号 | 特码 | T | Z | C | W | A | F

- ✓ = 开奖前锁定后命中
- × = 未命中
- F = 最终20码

不使用开奖结果倒推。

## 稳定趋势层
另外独立锁定并统计：

- 双波
- 7肖
- 大小
- 单双
- 波色单双3类
- 0/4杀头

每项显示真实：
- 最近10期
- 最近30期
- 最近60期
- 当前连中
- 历史最长连中

当前连中达到5期后，网页会自动显示“连中预警”。

## 20码 / 27码
继续继承 v32：

### 20码
- 每期一换
- 冷肖反转复审
- 最终最冷3肖不取
- 21~27名边缘救援
- 英文逗号一键复制

### 27码
- 10期一换
- 必杀0/4其中一头
- 趋势 + 纠错AI + 历史战绩三票制
- 英文逗号一键复制

## 数据继承
新增模型与稳定信号全部直接使用原 `prediction_log` 保存，因此原有 Supabase 检查点会一起备份：

- 历史开奖记录
- 旧实盘验证
- 20/27码成绩
- AI基础权重
- 纠错AI
- 排名审计
- T/Z/C/W/A/F锁单结果
- 稳定趋势连中记录

旧数据不会因为升级清零。

> 这项升级的价值在于发现“哪类逻辑当前真正提供独立命中”，并据此调整权重。彩票结果具有随机性，多模型与连中统计不能保证未来命中率提高。
