最初500期热身，其余按时间约50%/25%/25%分为选择段、验证段和最终测试段。选择段只挑一个候选，后两段不允许改选。正式记录与回测严格分开。随机对照是同码数、固定种子的等概率抽样，种子只依赖开奖前历史；并同时对比22/49与16/49的理论基线。

替换条件：验证段与测试段均显著优于随机理论基线和现有算法（单侧精确检验，三组校正p<0.05/3），且测试段前后两半的收益均为正。三组从选择段选出的候选都是冷码，均未通过替换条件。
