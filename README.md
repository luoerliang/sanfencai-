# 三分六合彩 v45

## 1. F动态增加“已开 / 中 / 错”

F动态号码下面现在直接显示：

`已开 12期 · 中 8期 · 错 4期`

这个统计使用 v45 自己的独立真实锁单 profile：
`F动态v45`

所以旧版本F逻辑的成绩不会混进来。

## 2. 冷三肖规则再次收紧

你这次强调的是：

> 本轮六类波色单双里杀掉哪两类，冷三肖每个生肖就必须选2个“属于这两类杀码”的号码。
> 没被杀的波色单双不要。

例如本轮杀：

`红单 + 蓝双`

当前最冷3肖：

`鼠、狗、猪`

那么：
- 鼠的2码：必须都是红单或蓝双
- 狗的2码：必须都是红单或蓝双
- 猪的2码：必须都是红单或蓝双

绿单、绿双、红双、蓝单都不能作为这3个冷肖的2码。

### 杀头仍参与
优先避开当前杀头。

如果某个冷肖在“被杀波色单双 + 避开杀头”后不足2码：
- 仍然只允许从被杀波色单双中补
- 不会拿没被杀的波色单双来凑数
- 如果补码碰到杀头，会在内部记录为“冷肖防守撞杀头”，不会偷偷混入非杀码

## 3. 27码变码 = 新开10期

以前变码后页面还沿用旧轮：
`本轮不变 / 已开不变`

v45修正为：

只要27码正式变码：
- 新号码从当前目标期开始
- 重新计算10期区间
- 已开归0
- 中归0
- 错归0

例如旧轮：
`20260925028 — 20260925037`

打到中途发生变码，新号码目标期是：
`20260925035`

页面立即变成：
`本轮 20260925035 — 20260925044`
`已开 0/10期 · 中0期 · 错0期`

这样一组27码只对应自己那10期成绩。
