# 三分六合彩 v46

## 修复：27码变码后，本轮/已开没有跟着重置

v45虽然后台已经把“变码 = 新开10期”写进策略，
但页面统计有一个时序问题：

1. 后台先算出新27码和新轮次
2. `stats27` 此时可能仍然只查到旧轮的真实锁单记录
3. 页面又优先显示旧 `stats27.current`
4. 因此出现：
   - 号码已经换了
   - 本轮起止期还是旧的
   - 已开/中/错还是旧的

v46从前后两层一起修复。

### 现在只要正式变码
例如新27码从 `20260925052` 开始：

页面马上变成：

`本轮 20260925052 — 20260925061`

`已开 0/10期 · 中0期 · 错0期`

不会再等 prediction_log 下一次写入才更新。

等25052真实开奖后才变成：

`已开 1/10期 · 中1期 · 错0期`

或：

`已开 1/10期 · 中0期 · 错1期`

## 冷三肖也直接显示具体号码

页面现在会直接显示类似：

`冷3肖 鼠:09/21 · 狗:13/37 · 猪:17/29 · 6/6杀码✓`

这样能直接核对：
- 哪三个是冷肖
- 每肖是不是正好2码
- 6个码是不是都按当前两种被杀波色单双进入

如果不足6个，会显示：

`冷肖码待补`

不会用没被杀的波色单双偷偷凑数。

- 正式变码 -> 立即重新开10期
- 冷三肖每肖固定2个“被杀波色单双”号码
- 普通生肖最多3码
- 第28码强信号保险
- 480跨日

- 缓存自愈
