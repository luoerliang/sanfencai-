# 三分六合彩 v47：F动态每20期一轮

## F动态改成20期轮次

F号码本身仍然：
- 每期开奖后重新计算
- 动态19~23码
- T/Z/C/W/A模型池继续学习
- AI纠错继续参与
- 3/5共识与强2/5规则继续保留

但F的成绩统计现在改成：

`每20期 = 一轮`

页面显示例如：

`本轮 20260925040—20260925059`

`本轮20期 · 已开 8/20期 · 中6期 · 错2期`

## 满20期后

第20期结算完成后，下一期自动：

- 新开一轮20期
- 已开归0
- 中归0
- 错归0
- 用已经学习到的最新模型权重继续重算F号码

例如上一轮结束后，下一期页面直接显示：

`本轮 20260925060—20260925079`

`本轮20期 · 已开 0/20期 · 中0期 · 错0期`

## 不丢当前成绩

v45开始已经真实锁单的F成绩继续算当前这一轮，
不会因为部署v47突然清零。

只有真正开满20期后，才自动进入下一轮。
