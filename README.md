# v65.1 修复说明

v65 的 D组“波色+大小”联合配额使用 `itertools.product`，
但原包只在另一个函数内部局部导入了 itertools。
因此后台完整模型构建走到 D组时会报 NameError，
页面就会一直停在“模型后台初始化中 / 0/0 / --码”。

v65.1 只修复这个初始化错误，算法本身不变：
- D组仍是16码
- 波色：模型60% + 最新10期40%
- 大小：模型60% + 最新10期40%
- 每期开奖后动态重算
- F/A/B/C全部保持原样

# 三分六合彩 v65：D组16码加入大小

## D组现在同时看两条线

### 1. 波色
仍然是：
- 多策略池正式波色模型：60%
- 最新10期实际特码波色：40%

得到红 / 蓝 / 绿强弱和16码里的波色配额。

### 2. 大小
新增：
- 六模型综合池聚合出来的大/小强弱：60%
- 最新10期实际特码大小：40%

大小定义沿用程序：
- 小：01~24
- 大：25~49

程序会得到下一期大/小的融合强度，
并把16码动态分成大码和小码席位。

为避免过度偏一边：
- 大码最低6个、最高10个
- 小码自然为其余6~10个

## 最终16码怎么选

程序同时满足：
- 红/蓝/绿动态配额
- 大/小动态配额

然后在六个交叉区里挑码：
- 红大
- 红小
- 蓝大
- 蓝小
- 绿大
- 绿小

每个交叉区内再按：
`六模型综合分 + 波色模型分 + 当前波色/大小融合强度`
挑更强的号码。

D仍然：
- 固定16码
- 每期开奖后动态重算
- 独立20期轮次统计
- 独立累计实盘

v65使用新profile：
`16D波色大小+近10期v65`

旧v64 D成绩保留在累计里，但新算法自己的本轮从v65独立统计。
