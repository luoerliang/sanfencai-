# 三分六合彩 v37：27码未来10期覆盖模型

## 这次最重要的改变
20码/F 和 27码现在是两个完全不同的目标。

### F动态19–23
继续做“下一期”。
目标：下一期尽量精准。

### 27码
专门做“未来10期累计覆盖”。
目标：这一组号码连续打10期后，累计中得更多。

不再用“下一期最强27码”的思路去做10期方案。

## 27码如何选
每轮开始时，系统一次性生成基础27码。

核心评分：

1. **历史相似状态 -> 后续10期出现了哪些特码**：52%
2. **T/Z/C/W/A模型的10期覆盖能力**：40%
3. **近80期号码稳定度**：8%

其中T/Z/C/W/A权重不再看单期命中，而是看：

> 某一期锁定的模型号码，拿去覆盖“该期 + 后9期”，10期能中几次。

因此它直接学习“10期覆盖”能力。

## 历史10期相似状态
系统比较当前最近10期与历史状态的：

- 生肖结构
- 头数结构
- 红单/红双/蓝单/蓝双/绿单/绿双结构
- 最新一期生肖/头数/波色单双

找到相似历史状态后，统计这些状态后面的10期特码去了哪些号码。

这部分是27码最大的权重。

## 27码一轮怎么运行
新逻辑不绑定“期号尾数0~9”。

部署后第一次生成27码时，就是新一轮第1期：

- 第1期：生成并锁定基础27码
- 第2~10期：基础27码保持不变
- 第10期结束：统计这一轮“10中几”
- 下一期：自动开始新一轮，再重新生成27码

这样才符合“这组27码拿来打10期”。

## 28码补位
轮内程序仍然每期开奖后重新分析未来剩余走势。

但：
- 不替换基础27码
- 不把27码每天乱换

如果发现基础27码之外有一个强号码，同时满足：
- 未来10期综合排名很靠前
- 多个T/Z/C/W/A模型同时支持
- 综合10期覆盖分达到高阈值

程序会：
1. 弹窗提醒
2. 把它临时加入
3. 当前显示为28码

## 0头/4头
27码的头数判断也改成“10期目标”。

不再判断：
> 下一期0头还是4头弱？

而是判断：
> 接下来这一轮10期，0头/4头哪个整体更弱？

而且因为一旦杀错会影响整轮10期，所以阈值比以前更严格：
- 10期综合分差必须明显
- 至少3/5模型支持同一个弱头

证据不够就不杀。

## 独立实盘统计
新27码使用新的profile：

`27码十期覆盖`

因此：
- 旧27码记录不会删除
- 旧数据继续继承
- 新10期模型从部署后真实锁单开始验证
- 不把旧单期逻辑成绩冒充新10期成绩

页面会显示：
- 当前第几/10期
- 本轮中了几期
- 已完成多少轮
- T/Z/C/W/A拥有多少个10期历史窗口样本

## F动态19–23
v36的逻辑原样保留：
- 模型池主导
- 3/5共识保护
- 强2/5优先
- 动态19~23码
- 23码限频

## 数据继承
Supabase、开奖记录、原AI、纠错AI、T/Z/C/W/A/F历史全部保留。

新27码的真实预测仍写入 prediction_log，因此会继续进入现有远程检查点。

> 彩票开奖结果具有随机性。10期模型是在优化历史条件下的累计覆盖目标，不保证未来某一轮一定达到指定命中次数。
