# 三分六合彩 AI×趋势互补版 v30：重点生肖3码 + 紧凑界面

## 目标
不再只是 `AI 38% + 趋势 62%` 的加权平均。

现在24码使用：
**共识优先 + 分歧互补 + 独立实盘验证**

## 24码生肖配额
- 重点生肖：3码
- 防守生肖：1码
- 其余10个生肖：各2码
- 合计仍为24码，每期开奖后重新计算
- 四肖一码继续独立计算，不受24码配额显示替代

## 24码内的生肖位置
- 普通生肖保留共识码和互补码。
- 重点生肖在这两个位置之外，再加一个同生肖高分码。
- 防守生肖只保留一个稳定码，用来给重点生肖让出一个名额。

不会因为某一边短期高一点，就把另一边全部压掉。

## AI/趋势补位名额怎么分
程序读取真实 `prediction_log`，比较同一期：

- 双方都中
- AI独中
- 趋势独中
- 双方都错

然后决定普通生肖的“第二码席位”怎么分给AI与趋势；重点生肖的第三码从该生肖完整排序中补入。

保护范围：
- AI最少4席
- AI最多8席
- 趋势因此也最少4席、最多8席

避免任何一个模型垄断24码。

## 旧验证不会被清零
原来的：
- AI在线
- 趋势快/平衡等
- prediction_log
- 41+期真实验证
- AI权重

全部继续保留。

新增的是：
`互补在线`

它从本次更新部署后的下一期开始独立记录真实命中，
不会把历史开奖结果倒推成“假实盘”。

## 页面调整
- 24码卡片显示当期“重点肖×3 / 防守肖×1”。
- 卡片、按钮、号码和历史行统一缩小，减少页面高度。
- 只有数据真正变化时才重绘，历史滚动位置会保留，降低界面跳动。

“AI × 趋势互补”卡片显示：

- 双方都中
- AI独中
- 趋势独中
- 双方都错
- 当前AI/趋势第二码席位
- 互补在线几中几

## 数据安全
沿用v28F1：
- Render Free
- Supabase Free Storage
- 自动上传 `sanfen_ai_checkpoint.json.gz`
- 重部署后自动恢复
- Secret key 新版 `sb_secret_...` 支持
- prediction_log / AI权重 / learner_scores / 最近开奖记录一并备份

## 注意
互补机制的目的是利用两套模型“犯错位置不同”的信息，
不是保证命中率一定提高。新互补模型应以开奖前锁定后的真实样本评估。
