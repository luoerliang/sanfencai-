# 三分六合彩 v44：27码10期显示简化

基于 v43，只改前台显示，不改27码选码算法。

## 27码现在直接显示

例如：

`本轮 20260925030 — 20260925039`

`已开 4/10期 · 中 3期 · 错 1期`

下面再保留简短策略信息：

`杀 红双、绿单 · 0头 · 冷3肖各2码 · 变盘0`

不再把“核23、中几、机救”等内部术语放在主要显示位置。

## 统计口径

- 本轮起始期：当前10期长码轮次第1期
- 本轮结束期：起始期往后第9期
- 已开：本轮已经结算多少期
- 中：27/28码实际命中的期数
- 错：已开期数 - 命中期数

所以一眼就能看出：
- 这组27码要打哪10期
- 已经打了几期
- 当前中几期
- 当前错几期
