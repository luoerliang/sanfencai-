# 三分六合彩 v42：27码长码规则精确版

这是按你最后确认的规则重做的27码，不再使用上一版的“两类合计<=4”条件。

## 一轮10期

### 第一步：回看前20期波色×单双
固定统计：
- 红单
- 红双
- 蓝单
- 蓝双
- 绿单
- 绿双

直接找出 **出现最少的两类**。

例如：
- 红双最少
- 绿单第二少

本轮就把：
`红双 + 绿单`
作为两组弱结构杀号。

注意：
**只杀红双、绿单，不杀整个红波或整个绿波。**

### 第二步：回看前20期0头/4头
- 0头少 -> 杀0头
- 4头少 -> 杀4头
- 一样多 -> 不杀头

### 第三步：每个生肖最多3码
最终正常27码里，同一个生肖最多3个号码。

### 第四步：最冷3肖防守2码
最冷3肖不再整肖杀掉。

从最冷3肖里面，专门寻找：
- 属于本轮被杀的两种“波色×单双”
- 但 **不属于当前被杀0/4头**

的号码。

从中保留综合分最高的 **2个防守码**。

也就是：
- 正常号码避开两种弱波色单双
- 但最冷3肖反向留2个弱结构防守码
- 这2个码仍然必须遵守杀头

## 变盘规则
一轮开始后，正常长码不动。

如果当前被杀的0头/4头 **连续开出2期**：
1. 判定头数走势可能变盘
2. 重新回看最新20期
3. 重新找两种最少的波色×单双
4. 0/4头直接改杀“另一头”
5. 重新生成27码
6. 仍然属于同一轮10期，不重新计数

之后如果新的杀头以后又连续开出2期，也可以再次按相同规则复查。
