# 三分六合彩 v57：F减法重构 + A简化长码

## 这次只改F和A
B组27码、C组22码、平特一肖全部保持v56算法，不动。

---

## F动态 v57

以前的问题：
- 3/6号码太多，几乎把23个位置全占满
- 2/6虽然有人抓到，但没有区分“是哪两个模型搭档”
- 冷三肖还会给F号码扣分
- 正式六模型之外，旧AI/旧Trend又重复参与救援
- 程序已经6模型，但部分旧公式仍按5模型比例处理

v57改成：

### 4+/6：硬保护
只有6个模型里至少4个同时看中的号码，才真正强制保留。

### 3/6：只加分
3个模型同意不再自动占位置。
它只是排名加分，仍要和其他号码竞争。

### 2/6：看“搭档质量”
后台用真实开奖前锁单学习15种两模型组合。

例如：
`冷热 + 纠错`
如果历史上两者共同抓中的次数明显更好，
它们一起支持的号码优先。

最多保4个2/6号码。

### 1/6：最多2个独家救援
只有最近真实出现过“其他模型都没中、只有它中”的模型，
才有资格拿独家救援位。

### 删除三种干扰
F不再：
- 因冷三肖扣分
- 使用旧AI重复投票
- 使用旧Trend重复投票

六模型本身就是全部底座。

### 19~23码仍保留
默认20码。
只有第21/22/23名和20名分差很小时才扩码；
19/20出现明显断层才缩到19码。

不会再为了“保护规则”机械塞满23码。

---

## F新增原始Top23对照

每期开奖前后台同时锁两组：

1. `F六模型原始Top23v57`
2. `F动态v57减法融合`

开奖后自动比较：

- 原始23中，F没中 = 加工误伤
- 原始23没中，F中了 = 加工救回
- 两边都中 = 正常
- 两边都错 = 六模型底层没抓到

页面会直接显示：
`原始23中X · F中X · 加工救回X · 加工误伤X`

以后不再猜F到底是加工变好还是加工变坏。

---

## A组 v57

A组仍然是“10期长码”，但把硬规则大幅删除。

新A组：
- 使用原来的10期前瞻/相似历史/六模型长期评分
- 直接取综合排名Top27
- 一组固定打10期
- 第10期结束后下一轮重新计算

不再硬执行：
- 杀两种波色单双
- 杀0/4头
- 冷三肖每肖必须2码
- 生肖3码硬上限
- 变盘中途强行换码

这些信息不再能把模型Top27里的号码硬删掉。

所以A组现在的定位非常简单：

`长期十期模型Top27稳定组`

而B/C仍然是：
`只看最新20期、每期实时变化组`

三者职责彻底分开。
