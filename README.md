# 三分六合彩 v34：紧凑界面 + 10期一轮动态27码

## 界面
整体缩小：
- 卡片间距
- 标题/说明
- 趋势框/诊断框
- 号码球
- 模型池行高
- 统计框
- 历史开奖高度

目标是在手机上一屏看到更多内容，减少上下滑动。

## 20码
- 每期重算
- 不再因为0头/4头判断直接硬杀整头
- 头数强弱仍参与排序
- 冷肖反转复审、最终冷3肖、21~27边缘救援继续保留

## 27码：10期一轮
“10期一轮”只用于统计和观察，不再代表10期固定同一组号码。

每期开奖后：
- 重新计算下一期27码
- 当前10期轮次继续累计命中
- 下一轮重新计数

## 0头 / 4头
27码不再“必须杀一头”。

现在由 v33 的五套模型共同判断：
- T 趋势
- Z 生肖
- C 冷热
- W 波色单双
- A AI纠错

系统计算0头和4头的多策略加权强度。

只有：
- 弱势差距达到阈值
- 且至少60%的模型支持同一个弱头

才会把该头从27码中硬排除。

否则页面会显示：
“不强杀，0头/4头某一头略弱”。

## 27码外强共识 -> 第28码
每期27码生成后，再扫描27码之外的号码。

若某个号码：
- 至少4/5模型把它排进前27
- 或3个以上模型高度共识且综合分很强

系统会：
1. 弹窗提醒
2. 自动把该号码加入
3. 本期由27码变成28码
4. 一键复制自动包含第28码

如果这个号码与弱头排除冲突，必须达到更高的5/5模型共识才允许救回。

## 数据与统计
继续继承：
- v33模型池锁单
- 20码/27码历史实盘
- T/Z/C/W/A/F成绩
- 连中统计
- AI基础模型
- AI纠错模型
- Supabase远程备份

27码历史profile继续沿用，因此以前的实盘记录不会消失。

> 彩票结果具有随机性。条件杀头、28码补位和多策略模型不能保证未来命中率提高，仍以开奖前锁单后的真实样本评估。
