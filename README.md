# 三分六合彩 v32：误杀降权 + 边缘救援

在 v31“趋势主攻 + AI专门纠错”基础上，针对目前实盘暴露的三个问题升级：

1. 冷三肖误杀
2. 27码杀0/4头成功率不够
3. 实际特码经常落在21~27或28名以后

## 20码

仍然保持：
- 每期一换
- 最终最冷3肖彻底不取
- 前3热肖最多3码
- 其他入选生肖默认2码
- 弱0/4头可以杀

新增：

### 冷肖反转复审
先找原始冷3肖，再用三个独立信号复审：
- 生肖转移
- 20码纠错AI
- 最近7码生肖结构

同时得到至少两个支持、且综合反转分足够高的冷肖，会先救回。
然后重新排出“最终最冷3肖”。

所以规则没有取消：最终仍然杀3肖；只是减少把正在反弹的生肖误杀。

### 21~27名边缘救援
20码初选后，对完整排名第21~27名再复审一次。

救援分使用：
- 纠错AI 52%
- 生肖转移 28%
- 红/蓝/绿 × 单/双走势 20%

最多替换2码，而且只在同生肖内部替换，因此不会破坏原来的生肖配额。

## 27码

仍然保持：
- 10期固定一组
- 每组必杀0头或4头其中一头
- 最终最冷3肖不进入主体

### 杀头改成三票制
每轮开始时由三方投票决定杀0还是杀4：

1. 趋势头数模型
2. 27码纠错AI
3. 真实前瞻历史里“杀0”和“杀4”的各自成功率

历史成功率使用平滑，避免少量样本把整轮带偏。

页面会显示三票分别投了什么，以及杀0/杀4各自实盘成绩。

## 纠错AI：排名错误越严重，学习力度越大

以前21~27和28+都属于“错”。

v32改成：
- 21~27：中等纠错
- 28+：更强纠错
- 冷三肖误杀：额外加权
- 杀头误杀：额外加权

目标是把实际特码从28+逐渐推到前27，再进一步推到前20。

## 复制格式
20码和27码的一键复制全部改成英文逗号：

`01,04,05,08,...`

不再使用空格分隔。

## 数据继承
继续继承并备份：
- 所有开奖记录
- prediction_log
- 原AI权重
- 20码/27码纠错AI
- 排名审计
- 冷三肖误杀记录
- 杀头成功记录
- Supabase远程检查点

旧实盘成绩不会因为升级清零。

> 彩票结果存在随机性。这个版本是在减少可观察到的模型错误，不能保证未来命中率一定提高；仍应以部署后的真实开奖前锁定样本判断。
