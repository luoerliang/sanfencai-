# 三分六合彩 v60：稳定评估版

这版把目前最合理的算法组合固定下来，不继续频繁叠新规则。

## 继续使用的算法

- F动态：v59误伤控制
  - 纯六模型TopN为母池
  - 每期只允许0~2次严格证据替换
  - 真误伤持续高于救回时自动停止替换
  - 冷肖不扣分
  - 不再重复旧AI/Trend投票

- A组27码：v57
  - 10期长码
  - 纯十期前瞻模型Top27
  - 不硬杀波色单双/头数/冷三肖

- B组27码：v58
  - 原近20期算法保留
  - 尾数新增10%软评分
  - 尾数不硬杀整尾
  - 动态杀头、冷3肖各2码、其他肖≤3继续保留

- C组22码：v58
  - 独立22位优化
  - 不再直接截B前22
  - 杀头软降权
  - 冷3肖总保4~6码
  - 生肖数量软约束
  - 尾数10%软评分

- 平特一肖：v56多节奏动态

## v60新增：F基础20与临时加码贡献统计

从v60开始，每期开奖前另外锁定：
- F核心20贡献v60
- F第21码贡献v60
- F第22码贡献v60
- F第23码贡献v60

第21/22/23码只有当期真的扩到那个席位时才写记录。

页面会直接显示类似：
`核心≤20中12/25 · +21救2/8 · +22救1/4 · +23救0/2`

以后不用再靠截图人工判断“20码中得多还是临时加码中得多”。

## 为什么不再继续改核心算法

前面F/A/B/C已经连续改过多次。
如果每几期就换一次算法，任何统计都会被不同版本混在一起。

v60先固定核心算法，只继续记录：
- 同码数原始/F公平对照
- F救回/误伤
- F核心20与+21/+22/+23贡献
- 各组真实前瞻中/错

建议至少积累20~40期新样本，再决定下一轮是否改动。
