# 三分六合彩 v48：F真2/5保护 + 27码错因诊断

## F动态：修复“假4/4”

之前可能出现：

- 3/5保护19码
- 2/5候选4码
- F却只有20码

页面虽然写“2/5保4/4”，实际最终F里可能只有1~2个。

v48改成真正保护：

- 3/5 + 强2/5需要21码 -> F自动21
- 需要22码 -> F自动22
- 需要23码 -> F自动23
- 不需要扩码时继续20码为主
- 最大仍然23码

页面显示：
`2/5实保 4/4`

这个数字统计的是最终F里真实存在的号码，不再统计候选数。

如果共识总数极端超过23：
- 强2/5最多4席全部保留
- 其余位置保留最强3/5
- 总数仍不超过23

### F统计
因为F算法已经实质变化，v48使用新的独立真实锁单：
`F动态v48真2of5`

从部署后重新开始新的20期验证，避免和旧“假4/4”成绩混在一起。

## 27码：原始Top27平行对照

每期后台同时锁定：

1. 原始模型Top27
2. 经过波色单双 / 0·4头 / 冷三肖 / 生肖配额后的正式27码

不改变你正式使用的27码，只用于诊断。

以后正式27码没中时，程序自动判断：

- `底层模型没抓到`
- `波色单双杀错`
- `0/4头杀错`
- `冷肖每肖2码没覆盖`
- `生肖3码上限挤出`
- `结构截断`

这样可以知道到底是模型本身不行，还是某条硬规则把本来能中的号码删掉。

## 27码规则快照

每一轮10期都会保存：

- 本轮起止期
- 杀哪两种波色单双
- 杀0头还是4头
- 最冷三肖
- 冷三肖每肖哪2个码
- 原始Top27
- 最终生肖数量
- 变盘次数

所以一组27码连续跑10期时，页面和诊断不会再出现：

`cold3_codes: {}`
`cold_defense6: []`

这种“号码还在，但规则说明丢了”的情况。

- F号码每期开奖重算
- 27码正式变码立即重开10期
- 冷三肖每肖2个且必须来自两种被杀波色单双
- 普通生肖最多3码
