# v67.1 快速显示修复

修复 v67 在三分快三高速开奖环境里“最新开奖已经入库，但 F/A/B/C/D 长时间显示 --码”的问题。

原因：v67 把 BASE、旧规则、多个原子 Shadow 一起算在完整模型构建路径里。开奖频率高时，完整构建还没结束下一期开奖又到了，页面一直处于“模型重算中”。

v67.1 改成两层：
1. **快速 BASE 层**：新期开奖后优先计算并显示 F22 / A27 / B27 / C22 / D16，只算正式 BASE，不等待 Shadow。
2. **后台 Shadow 层**：4票、强3、2票、杀头、缺尾、波色、大小、旧v66继续后台锁单和验收，不阻塞页面出码。

另外增加：
- 完整模型如果算的是旧期号，不允许覆盖更新后的快速 BASE；
- 新期开奖刚入库时先清空上期号码，避免把上一期预测误当下一期；
- 页面状态会显示“BASE已出码 · Shadow后台更新”。

正式算法和 v67 的实验原则不变，本版只修实时显示/计算路径。
