# 三分六合彩 v68：49码概率排名 + 严格前瞻验收

这版不是“再加规则”，而是把模型评价方式重做。

## 正式Live结构
- **R1**：长窗概率排名器，输出49个号码完整概率；F=R1 Top22，A=R1 Top27。
- **R2**：短窗概率排名器（最新10期信号会向40期收缩）；C=R2 Top22，B=R2 Top27。
- **R3**：独立多尺度概率排名器；D=R3 Top16。

F/A不再被当成两个独立“投票模型”；C/B也一样。它们是同一母排序的不同覆盖切线。

## 每一期开奖前永久锁定
新表 `v68_forecast` 会保存：
- target_issue
- ranker_id / model_version
- history_cutoff_id
- 49码完整 probability
- 49码完整 rank
- Top16 / Top22 / Top27

开奖后只追加：
- actual_special
- actual_rank
- log loss
- Brier score
- Top16/22/27 hit

不会拿开奖结果回填预测。

## v68页面主指标
不再只看“累计中/错”，而是同时看：
- 同码数随机覆盖基准（16/49、22/49、27/49）
- coverage-adjusted Lift
- 真实特码平均排名（随机排序期望约25名）
- Log loss（均匀49分类基准 ln(49)≈3.8918）
- Brier score（均匀基准48/49≈0.9796）
- 95% Wilson区间 / 单侧binomial基准检验

## 晋级纪律
`300期`只是最低观察门槛，不是自动晋级条件。
还必须同时满足：
1. 主切线相对同码数随机基准有正提升；
2. 置信区间下界高于随机基准；
3. 单侧p值通过保守多重比较门槛；
4. Log loss优于均匀基准；
5. 真实特码平均排名有改善。

## 和v67.4的公平对照
v68会在开奖前同时锁定同码数的v67.4 Control。页面显示“对v67.4净贡献”。
只有前瞻Control长期胜出，才说明v68确实比旧BASE更好。

## 旧v67 Shadow
4票、强3票、杀头、缺尾、波色、大小等旧规则历史数据全部保留。
它们继续是研究数据，不因为短期几次救回就升回Live。
