# v70：47.5倍收益门控版

这版不声称提高随机开奖的可预测性，而是把“命中率看起来略高”与“47.5倍赔率下是否真的回本”分开。

## 核心公式
假设每个入选号码各押1单位，中奖时总返还47.5单位（含本金）：

- Top22 回本命中率 = 22 / 47.5 = 46.3158%
- Top27 回本命中率 = 27 / 47.5 = 56.8421%
- Top16 回本命中率 = 16 / 47.5 = 33.6842%

每期EV：
`命中率 × 47.5 - 号码数`

ROI：
`EV / 号码数`

## v70页面新增
F22 / A27 / B27 / C22 / D16 每组显示：
- 实盘样本数
- 实际命中率
- 95% Wilson区间
- 47.5倍回本线
- 相对回本线Edge
- 每期EV
- ROI

## 门控
只有：
`95%CI下界 > 回本命中率`
才显示“有正EV证据 · 仅进入人工复核”。

否则统一显示：
- 未证明正EV · STOP
或
- 负EV证据 · STOP

这能防止把“比N/49随机高一点”误判成可盈利优势。

## 算法
R1/R2仍冻结，不因输赢改参数。
v70先解决收益判断，不用历史结果追参制造假提升。

`SPECIAL_PAYOUT_TOTAL` 环境变量可修改总返还赔率，默认47.5。
